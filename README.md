# Bole Wereda 1 Official Website

Official website for **Bole Wereda 1**, an administrative division under the **Addis Ababa City Administration**.

## Getting Started

```bash
cd bole-wereda-website
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

- React + Vite
- Plain CSS Modules
- Fully static, no backend
